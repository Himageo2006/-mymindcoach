How to capture these as App Store screenshots:

1. Open Chrome DevTools → press F12
2. Click the device toolbar icon (📱) or press Ctrl+Shift+M
3. Set dimensions to 414 × 896 with 3x DPR → gives 1242×2688px
4. Right-click on the phone → "Capture screenshot" for each one

Or use: Ctrl+Shift+P → type "screenshot" → "Capture full size screenshot"
